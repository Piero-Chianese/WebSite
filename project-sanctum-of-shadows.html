Sanctum of Shadows

Unreal Engine 5 | Horror Game Jam

Description

Sanctum of Shadows is my first game developed in Unreal Engine 5. It was created in just one week for a horror-themed game jam, representing my first approach to the engine's capabilities.

The project allowed me to explore Unreal's lighting and atmosphere tools to create a chilling environment. My role in this project was Game Designer and Game Developer, handling everything from the initial concept to the final implementation of gameplay systems.

Platform Variations

In addition to the standard desktop releases, I also worked on VR and iPadOS versions of the game. While these versions have not been officially published, they served as valuable experiments in cross-platform development and immersive technology within Unreal Engine 5.
