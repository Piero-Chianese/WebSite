Day Count Redesign

UI/UX Case Study | Mobile Redesign

Objective

The goal of this project was to identify an existing app on the App Store and improve its overall User Interface (UI) and User Experience (UX). My choice fell on Day Count, an app with great utility but a suboptimal interface.

As a Full Stack coder, I completely redesigned the options menu and streamlined the core user flow to make the interface clearer and more intuitive for everyday use.

Redesign Process

I focused on simplifying the visual hierarchy and improving accessibility. The original app's menu was cluttered, leading to user confusion. In my version, I implemented a cleaner design language with consistent typography and more breathing room between elements.
